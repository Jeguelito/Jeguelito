# COTERI R.L. — Propuesta de rediseño

Sitio estático en español, adaptable a móviles, sin dependencias de ejecución. Estética tecnológica verde/cian, ilustración vectorial de red, navegación móvil y preguntas desplegables. Los recursos se sirven localmente.

## Ejecutar

Desde `/workspace/Jeguelito/coteri`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

## Estado del contenido

Esta es una propuesta visual preliminar. El proxy del entorno denegó la consulta de https://www.coteri.com.bo y https://coteri.com.bo con HTTP 403 el 8 de octubre de 2026. Un intento posterior a www.coteri.com.bo devolvió HTTP 503 con CERTIFICATE_VERIFY_FAILED desde el proxy; no se desactivó la verificación TLS. Por tanto, no se verificaron ni trasladaron los servicios, planes, tarifas, noticias, historia, identidad gráfica, teléfonos, direcciones ni horarios originales. El símbolo y los textos de portada son propuestas de diseño, no elementos obtenidos del sitio original.

No hay backend, envío de formularios, pagos ni área privada. Los enlaces externos dirigen al sitio solicitado por el usuario. Antes de publicar, consultar todas las páginas oficiales, sustituir los textos pendientes, incorporar los recursos de marca autorizados y verificar cada enlace y dato de contacto.
